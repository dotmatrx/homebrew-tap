# dotmatrx Homebrew tap

Homebrew casks for [dotmatrx](https://github.com/dotmatrx) open source projects.

| Cask | Description |
|------|-------------|
| [yadokari](https://github.com/dotmatrx/yadokari) | Unofficial terminal client for WaniKani reviews and lessons |

## Install

```sh
brew install dotmatrx/tap/yadokari
```

That adds the tap and installs the cask in one step. You can also add the tap first
with `brew tap dotmatrx/tap`, then install by name: `brew install yadokari`.

The binaries aren't signed or notarized, so the cask clears macOS's quarantine flag on
install. Without that, Gatekeeper would refuse to run them.

## Upgrade

```sh
brew update
brew upgrade yadokari
```

## Uninstall

```sh
brew uninstall yadokari
brew untap dotmatrx/tap   # optional: removes the tap itself
```

Uninstalling leaves your settings, data and saved token in place. Each project's README
says where they live.

## Maintenance

The casks in `Casks/` are generated by [GoReleaser](https://goreleaser.com) when a
project tags a release. Don't edit them by hand, because the next release overwrites
them. Fix the project's `.goreleaser.yaml` instead. Report problems with a cask in the
project's own repository.
